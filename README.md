# স্বপ্নযান (Shopnojan) — আয়-ব্যয়ের হিসাব

A simple, fast **Bengali income–expense tracker** web app. Track your daily আয় (income) and ব্যয় (expense), see summaries at a glance, and keep your personal finances organized — right from the browser, no install needed.

## ✨ Features

- 📊 **Today's summary** — income, expense & balance at a glance
- 🗂️ **Categories** — organize expenses by category
- 📅 **Daily tracking** — date-wise income & expense records
- 🇧🇩 **Fully in Bengali** — interface designed for Bangladeshi users
- 📱 **Mobile-friendly** — responsive design, works on any device
- ⚡ **Zero setup** — single-page web app, just open and use

## 🚀 Usage

Open `index.html` in any modern browser — that's it. No build step, no server required.

## 🛠️ Tech

- HTML5 · CSS3 · Vanilla JavaScript
- Local, in-browser data handling
