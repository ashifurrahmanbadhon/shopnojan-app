# স্বপ্নযান (Shopnojan) — Daily Income & Expense Tracker

A simple, fast, and elegant **Daily Income & Expense Tracker** web app featuring the **V6.3 Ledger Pro** theme. Track your daily income and expense, filter records by month, view summaries at a glance, and keep your personal finances organized — right from the browser with local storage persistence and backup/restore.

## ✨ Features

- 📖 **Ledger Pro Theme** — Classic dark ledger book styling with cover and stitch accents
- 📊 **Dashboard at a Glance** — Today's balance, today's income & expense, and monthly/overall totals
- 📅 **Monthly Filterable Ledger** — Clickable Total Income / Total Expense / Total Balance cards to instantly filter transactions
- ✏️ **Edit & Delete** — Full control over Today's and Monthly transactions
- 💾 **Data Backup & Restore** — Export records as JSON and restore from file anytime
- 📱 **Mobile-friendly** — Responsive mobile design, works seamlessly in browser or WebView APK
- ⚡ **Zero Setup** — Single-file web app, no build step or server required

## 🚀 Usage

Open `index.html` in any modern browser — that's it. No build step, no server required.

## 🛠️ Tech

- HTML5 · CSS3 · Vanilla JavaScript
- LocalStorage persistence (`swapnojhan_v2`)
